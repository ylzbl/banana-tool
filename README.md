## 工具定位

Banana Tool 是为内容团队设计的 **AI 信息图提示词组装工具**。它不直接出图，而是把"从文章到 AI 出图"中间那段最容易丢信息、最容易风格漂移的提示词组装环节，做成可视化的 4 步工作流，让团队复用同一套 VI 规范反复出图。

核心解决的问题：

- 手工拼提示词容易漏掉文章里的关键数据点
- 同一系列多张图风格不统一
- 公司 VI（颜色、字体、插画风格）每次都要重写一遍
- 出图后还要手动加 Logo 水印

## 4 步工作流

### 步骤 1 · 解读提取
粘贴文章全文 → 输入关键主题 → 选择 AI 模型（推荐 Gemini 3 Pro 或 Claude Opus）→ 生成提取提示词 → 复制到 AI 对话 → 把 AI 返回的提取结果粘回右侧输入框。

### 步骤 2 · VI 套用
左侧填公司视觉规范（主色、辅色、字体、插画风格、版式偏好），右侧填主标题（强调字用【】包裹）、副标题、内容主体、可选结论文字，切换到「预览效果」查看信息图布局。

### 步骤 3 · 组装出图
点击「组装提示词」自动生成完整提示词 → 一键复制 → 粘贴到 Nano Banana Pro / 即梦 / Midjourney 等出图工具。

### 步骤 4 · 后处理
上传生成的图片（支持拖拽）→ 上传横版 Logo（页脚）和竖版 Logo（水印）→ 调整水印透明度和混合模式 → 应用 → 下载成品。

## 使用方法

### 快速开始
直接双击 `index.html` 即可在浏览器中运行。**无需服务器、无需安装、无外部依赖、无后端调用**，所有数据保存在浏览器 `localStorage` 中。

### 部署方式
- **本机浏览器直接打开**：双击 `index.html`
- **GitHub Pages**：已启用 Pages，访问 https://ylzbl.github.io/banana-tool/
- **Cloudflare Workers**：将 `index.html` 作为响应体返回（适合自定义域名 + CDN 加速）

### 配置管理
- 点击右上角 ⚙️ 按钮可导出 / 导入 JSON 配置（含 VI 规范、历史项目、提示词模板）
- 支持多项目管理，每个项目独立保存
- 清除浏览器数据会丢失配置，建议定期导出备份

## 注意事项

1. Nano Banana Pro 的"图像生成"模式**不可叠加附件**，请使用纯文本提示词
2. 提示词中的数据会 100% 输出到图中，请仔细核对事实准确性
3. 同一系列多张图需在提示词中显式指定与第一张相同的风格
4. 中文标注建议后期叠加（多数模型中文渲染不稳定），prompt 中保留英文标注即可
5. 步骤 4 的水印功能基于 Canvas，对大图（>8K）可能卡顿
