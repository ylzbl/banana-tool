# Banana Tool - AI信息图提示词工坊

## 工具用途

Banana Tool 是一个AI信息图提示词组装工具，将手动操作的提示词工作流转化为可视化流程。

它帮助您：
- 从文章中提取关键信息，组装AI提示词
- 套用公司VI视觉规范，生成统一风格的信息图提示词
- 一键组装完整的出图提示词，复制后粘贴到Nano Banana Pro等AI出图工具
- 对生成的图片添加Logo水印等后处理

## 使用方法

### 快速开始

解包后直接打开 `index.html` 即可使用。无需服务器、无需安装、无外部依赖。

### 4步工作流

#### 步骤1：解读提取
1. 粘贴文章全文
2. 输入关键主题（必填，如"荧幕小三形象发展历程"）
3. 选择AI模型（推荐Gemini 3 Pro或Claude Opus）
4. 点击「生成提取提示词」→ 复制到AI对话框
5. 将AI返回的提取结果粘贴到右侧输入框

#### 步骤2：VI套用
1. 左侧配置公司视觉规范（颜色、字体、插画风格等）
2. 右侧填写主标题（强调字用【】包裹）、副标题、内容主体
3. 切换到"预览效果"查看信息图布局
4. 可选填结论文字

#### 步骤3：组装出图
1. 点击「组装提示词」自动生成完整提示词
2. 点击「一键复制」复制到剪贴板
3. 粘贴到Nano Banana Pro出图

#### 步骤4：后处理
1. 上传生成的图片（支持拖拽）
2. 上传横版Logo（页脚）和竖版Logo（水印）
3. 调整水印透明度和模式
4. 点击「应用水印」→ 下载成品

### 部署方式

支持以下部署场景：
- **本机浏览器直接打开**：双击 `index.html`
- **GitHub Pages**：推送到仓库，启用Pages
- **Cloudflare Workers**：将 `index.html` 作为响应返回

### 配置管理

- 所有数据保存在浏览器 localStorage 中
- 点击右上角 ⚙️ 按钮可导出/导入配置（JSON文件）
- 支持多项目管理

## 注意事项

1. Nano Banana Pro的"图像生成"模式**不可叠加附件**，请用纯文本提示词
2. 提示词中的数据会100%输出，请仔细核对事实准确性
3. 系列图片需指定与第一张图同样的风格以保持统一
4. 中文标注建议后期叠加（多数模型中文渲染不稳定），prompt中保留英文标注即可
5. 清除浏览器数据会丢失配置，建议定期导出备份

## 智能体策划过程备忘

### 需求理解
用户需要将一个手动操作的提示词工作流（提取文章→套用VI→出图→后处理）转化为一个可视化产品页面。核心目的是让领导看到成型的科技产品而非工作流截图。因此产品需要：
- 高度直观，截图后也能让领导理解工作原理
- 实际作用是组装prompt+加水印，不需要在该界面调用API
- 自包含单文件HTML，减少外部依赖

### 设计决策
1. **4步Pipeline**：将文档中的4个步骤可视化为步骤条，每步有明确的状态指示
2. **VI侧栏**：将公司视觉规范集中展示在左侧，包含色板、字体、插画风格
3. **实时预览**：步骤2中"编辑/预览"双标签切换，让用户看到信息图布局效果
4. **深色代码区**：步骤3的提示词展示采用IDE风格的深色背景+语法高亮
5. **水印工具**：步骤4提供Canvas操作，支持多种水印模式

### 踩坑记录
1. GitHub Pages API需要admin权限才能通过API创建，但push权限足够推送gh-pages分支
2. 仓库已有main分支，需要先pull再push
3. VLM分析截图发现多个bug：步骤状态不一致、文本溢出、预览渲染问题
4. 拖拽上传需要阻止默认行为和添加视觉反馈
5. step2的自动填充逻辑需要注意不要覆盖已有内容
